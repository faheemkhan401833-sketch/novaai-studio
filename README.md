# NovaAI Studio - Commercial SaaS v2.0

A modern, responsive AI Content & Code Generation SaaS web application built with clean HTML5, CSS3, and Vanilla JavaScript.

## Included AI Tools (8 Modules)
1. Blog Article Writer
2. YouTube Script Pro
3. Viral Social Captions
4. Cold Email Generator
5. Smart Summarizer
6. Code Debugger Pro
7. Ad Copywriter
8. SEO Keyword Finder

## Key Features
- Dark & Light Mode Toggle
- Tone, Length, and Multi-Language Selection
- Real-time Word & Character Counter
- Client-side API Key Management (No backend server required)
- 100% Mobile & Desktop Responsive UI

## How to Setup & Run
1. Extract the ZIP folder.
2. Open `index.html` in any browser or upload the folder to Netlify, Vercel, or any shared hosting.
3. Click on **API Key Settings** in the sidebar.
4. Enter your OpenAI or Google Gemini API key and click **Save**.
5. Select any AI tool, enter your prompt, and click **Generate AI Content**.
